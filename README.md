# Λιμενική Αστυνομία — Ηλεκτρονικές κλήσεις

Ψηφιακή καταχώρηση κλήσεων οχημάτων (Έκθεση Βεβαίωσης Παράβασης — Ν. 5209/25) για χρήση από λιμενικό σε tablet, με admin πίνακα εύρεσης και οριστικοποίησης.

## Τι περιλαμβάνει

- **Νέα κλήση** (`/klisi`): φόρμα σε βήματα με στοιχεία οδηγού/οχήματος, checklist παραβάσεων ΚΟΚ, πρόστιμο, κατάσχεση εγγράφων, τόπο και ώρα.
- **Admin** (`/admin`): λίστα κλήσεων, φίλτρο ημερομηνίας, αναζήτηση πινακίδας, λεπτομέρειες και πράξη διοικητή (τρίημερο / αντιρρήσεις / εξόφληση).
- Αποθήκευση σε τοπικό αρχείο `data/citations.json` (χωρίς βάση δεδομένων στο πρώτο slice).

## Εκκίνηση

```bash
npm install
npm run dev -- -p 43123
```

Άνοιγμα: [http://127.0.0.1:43123](http://127.0.0.1:43123)

## Ιδέες επόμενων φάσεων

1. **Android app** (Capacitor/React Native) πάνω στο ίδιο API, με offline ουρά όταν δεν υπάρχει σήμα στο λιμάνι.
2. **Ρόλοι**: λιμενικός / διοικητής / λιμενικό ταμείο, με SSO ή υπηρεσιακό λογαριασμό.
3. **Πληρωμές**: αναφορά αριθμού κλήσης + πινακίδα, σήμανση εξόφλησης από email απόδειξης.
4. **Εκτύπωση / PDF** της έκθεσης για τον παραβάτη και το αρχείο.
5. **Υπογραφή στην οθόνη** (stylus) και φωτογραφία πινακίδας/θέσης.
6. **Στατιστικά** ανά αρχή, είδος παράβασης και εισπράξεις.
